## Selected Projects

### Smart Lighting Prototype
ML-based system for adaptive street lighting using traffic flow, time, and environmental data.  
Includes simulation, preprocessing, and model-based dimming prediction.

### Radar CNN Classification
Prototype for classifying **human / vehicle / other** using CNNs and synthetic radar-like representations, designed as a foundation for future real-radar integration.

### EV Charging Optimization
Simulation and comparison of charging strategies based on **electricity cost, charging constraints, and SOC targets**.

Exploratory project using **contextual bandits and Fourier-based adaptation** to dynamically optimize EV charging profiles under realistic constraints.

Experiments with **ROS 2, OpenCV, COLMAP, Python, and image-processing pipelines** for robotics and perception applications.
