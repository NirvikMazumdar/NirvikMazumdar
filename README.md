## Projects

### Smart Lighting Prototype
ML-based system that adapts street lighting using traffic flow, time, and environmental data.  
Includes simulation, preprocessing, and model-based dimming prediction.

### Radar CNN Classification
Object classification (human / vehicle / other) using CNNs with synthetic radar-like representations.  
Designed as a prototype for future integration with real radar datasets.

### EV Charging Optimization
Comparative analysis of charging strategies based on cost and SOC targets.  
Includes simulation of charging behavior under electricity price constraints.

### Contextual Bandit Charging Optimization
Exploratory project using contextual bandits and Fourier-based adaptation to dynamically optimize EV charging profiles under realistic constraints.
